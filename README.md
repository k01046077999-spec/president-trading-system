# 대통령매매법 v1.8 강화판

핵심 개선:
- 다이버전스 탐지를 종가 기준에서 `저가(low)` 기준으로 강화
- 최근 저점 2개가 너무 붙어있거나 너무 멀면 제외
- RSI 다이버전스의 최소 강도와 가격 이탈 허용폭을 추가
- 4시간봉 추세 필터(EMA50/EMA200, EMA 기울기) 추가
- 1시간봉 진입 확인(20EMA 상향 회복 + 직전 캔들 양봉) 추가
- ATR 기반 손절 버퍼 추가로 휩쏘 손절 완화
- RR 기준 강화 (메인 1.3 -> 1.8, 서브 0.9 -> 1.2)
- 과열 반등/추격 진입 방지 필터 추가

핵심 아이디어:
1. 단순히 "다이버전스가 보인다"가 아니라,
2. "저점 구조가 깔끔하고",
3. "상위 타임프레임 하락 추세가 너무 강하지 않으며",
4. "실제 반등 재개 확인이 나온 뒤",
5. "손절은 구조 + 변동성 버퍼로 둔화"
이 다섯 가지를 동시에 만족할 때만 메인 신호를 내보냅니다.
